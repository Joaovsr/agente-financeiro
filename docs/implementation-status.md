O webhook rejeita texto acima de 10 mil caracteres antes de persistir o evento; o teste de regressão passa com transporte ASGI local. A edição de uma programação preserva ocorrências vencidas anteriores à substituição que ainda não tinham sido geradas por consulta. A suíte completa passou em Python 3.12 no host Windows em 2026-09-24: 96 testes passaram e um teste PostgreSQL foi ignorado sem `TEST_POSTGRES_URL`. Esse teste PostgreSQL foi executado separadamente em um banco temporário no Docker e passou. O SQLite dos testes precisou usar um diretório temporário nativo do Windows; quando o banco temporário ficou em caminho WSL, surgiram bloqueios de arquivo que não ocorreram no diretório nativo.

## Próximas verificações para concluir a meta

1. Escolher a hospedagem para operação contínua, subir a API por HTTPS e registrar o webhook público.
2. Repetir migrações e restauração de cópia no PostgreSQL do piloto; o banco Docker usado aqui é descartável.
3. Testar voz, imagem e PDF enviados pelo Telegram e revisar a qualidade das propostas com documentos representativos.
4. Verificar a entrega real de lembrete, alerta e resumo no chat privado correto.
5. Revisar saldos e previsões com exemplos do dono e repetir as avaliações depois de mudanças no modelo ou nas instruções.

Para o primeiro piloto, use uma instância da API e um processo de agenda. A concorrência entre múltiplas instâncias ainda não foi validada com PostgreSQL.

A migração `c91d5b73e0a2` registra o tipo dos novos comandos para compor respostas de recuperação quando uma escrita foi confirmada antes de uma interrupção. Ela passou em PostgreSQL 16 temporário, com o ciclo financeiro e `alembic check`. Comandos anteriores à migração ainda podem ser identificados como confirmados, mas podem receber um resumo genérico.

A migração `84df5cae7021` remove preferências de carteira padrão que podem ter sido atribuídas automaticamente pela versão anterior. Depois de atualizar uma base existente com várias carteiras, o dono deve escolher novamente sua carteira padrão, se quiser lançamentos sem indicar a carteira.

Em 2026-09-24, foram conferidos na documentação oficial da OpenAI o [alias `gpt-5.6`](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-5.6), o [fluxo de chamadas de ferramentas da Responses API](https://developers.openai.com/api/docs/guides/function-calling), o [envio de PDF como `input_file`](https://developers.openai.com/api/docs/guides/file-inputs) e o [suporte a WebM na transcrição de arquivos](https://developers.openai.com/api/docs/guides/speech-to-text). Essas referências confirmam o formato documentado das integrações, mas não comprovam acesso da conta nem comportamento com chamadas reais.
